# Guitar Pro X

Downloads for Guitar Pro X: read, hear and practice your Guitar Pro tabs.

Get the latest version from [Releases](https://github.com/kodydeda4/guitar-pro/releases/latest):

- **macOS:** [GuitarProX.dmg](https://github.com/kodydeda4/guitar-pro/releases/latest/download/GuitarProX.dmg)
- **Windows:** [GuitarProX-Setup.exe](https://github.com/kodydeda4/guitar-pro/releases/latest/download/GuitarProX-Setup.exe)
- **Linux:** [GuitarProX.AppImage](https://github.com/kodydeda4/guitar-pro/releases/latest/download/GuitarProX.AppImage) or [GuitarProX.deb](https://github.com/kodydeda4/guitar-pro/releases/latest/download/GuitarProX.deb)

The app updates itself from here. This repository holds only the release builds.
